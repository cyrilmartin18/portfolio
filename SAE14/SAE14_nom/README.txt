1. PRÉSENTATION DU PROJET

Ce projet a été réalisé dans le cadre de la SAE14 (Se présenter sur Internet), durant la première année du BUT Réseaux et Télécommunications.

L'objectif de ce projet est de créer un portfolio personnel afin de présenter mon parcours scolaire, mes compétences, mes projets, mes centres d'intérêt et mon projet professionnel.

Ce portfolio permet également de découvrir mon profil et les connaissances que je développe dans le domaine des réseaux informatiques et des télécommunications.

Le site est disponible en deux langues :
- Français
- Anglais

3. DESCRIPTION DES PAGES DU SITE

Page d'accueil (index.html)

Cette page présente mon identité, ma formation en BUT Réseaux et Télécommunications ainsi qu'une introduction à mon portfolio.

Elle contient également :
- Une présentation personnelle.
- Une image de profil.
- Un lien vers mon CV au format PDF.
- Une présentation de la formation R&T.
- Des liens vers les autres pages du site.

Page parcours (parcours.html)

Cette page présente mon parcours scolaire et universitaire, mes compétences informatiques et techniques ainsi que mes connaissances dans le domaine des réseaux et des télécommunications.

Elle permet également de présenter mes objectifs d'apprentissage et mon évolution.

Page projets (projets.html)

Cette page présente mes projets personnels et universitaires, mes réalisations, mes centres d'intérêt et mes activités.

Elle permet de montrer les compétences acquises et les connaissances développées au cours de ma formation.

Page contact (contact.html)

Cette page permet aux visiteurs de découvrir les moyens de me contacter ainsi que les informations utiles concernant ma formation.

Pages anglaises

Chaque page possède une version anglaise afin de rendre le portfolio accessible à des visiteurs anglophones.

La navigation permet de passer facilement du français à l'anglais.


4. TECHNOLOGIES ET OUTILS UTILISÉS

HTML5 :
Utilisé pour créer la structure des pages web, organiser les contenus et intégrer les liens, les images et les différentes sections.

CSS3 :
Utilisé pour personnaliser l'apparence du site, les couleurs, les polices, les espacements, les menus, les boutons et la disposition des éléments.

Visual Studio Code :
Éditeur de code utilisé pour écrire, modifier et organiser les fichiers HTML et CSS.

Live Server :
Extension de Visual Studio Code permettant de visualiser le site dans un navigateuret de voir les modifications pendant le développement.

Navigateurs web :
Google Chrome et Microsoft Edge sont utilisés pour consulter et tester le portfolio.


5. COMMENT OUVRIR LE SITE ?

Pour ouvrir le portfolio, plusieurs possibilités existent.

Méthode 1 : avec Visual Studio Code et Live Server

1. Ouvrir Visual Studio Code.
2. Ouvrir le dossier contenant le projet.
3. Sélectionner le fichier index.html.
4. Cliquer sur « Go Live » en bas à droite.
5. Le site s'ouvre automatiquement dans le navigateur.

Méthode 2 : directement avec un navigateur

1. Ouvrir le dossier du projet dans l'explorateur Windows.
2. Rechercher le fichier index.html.
3. Faire un double-clic sur ce fichier.
4. Le portfolio s'ouvre dans le navigateur par défaut.


6. NAVIGATION SUR LE SITE

La navigation principale permet d'accéder aux différentes rubriques du portfolio :

- Accueil : présentation générale.
- Parcours : formation et compétences.
- Projets : réalisations et centres d'intérêt.
- Contact : informations de contact.

Un menu de langue permet également de passer de la version française à la version anglaise.

Les liens externes permettent de consulter des ressources complémentaires, notamment la présentation officielle du BUT Réseaux et Télécommunications de l'Université de Rouen Normandie.


7. RESPONSIVE DESIGN

Le site a été conçu pour s'adapter à différentes tailles d'écran.

L'utilisation du CSS permet d'améliorer l'affichage sur ordinateur, tablette et téléphone.

Des règles CSS spécifiques permettent d'adapter a disposition des éléments lorsque la largeur e l'écran est réduite.

Les images sont également adaptées à la taille de leur conteneur afin de conserver un affichage correct.
